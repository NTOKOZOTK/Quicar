# QUICAR - Buy Your Car 100% Online

QUICAR is a modern car marketplace app that allows users to browse, finance, and purchase vehicles entirely online.

## Features

- User authentication and verification
- Car browsing with filters
- Favorites system
- Car details with financing calculator
- Multi-step checkout process
- Admin dashboard

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
\`\`\`bash
git clone https://github.com/yourusername/quicar-app.git
cd quicar-app
\`\`\`

2. Install dependencies
\`\`\`bash
npm install
\`\`\`

3. Start the development server
\`\`\`bash
npm start
\`\`\`

The app will be available at http://localhost:3000

## Project Structure

- `/src` - Source code
  - `/components` - Reusable UI components
  - `/pages` - Page components
  - `/context` - React context for state management
  - `/utils` - Utility functions
